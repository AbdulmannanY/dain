# Dain (دائن)

A two-sided debt ledger for people and shops: either side records an entry,
the other side confirms or disputes it.

- `supabase/` — Postgres schema (RLS, RPCs) and its SQL tests
- `app/` — Flutter client (Android + web)
- `docs/project-context.md` — the project reference (start here)
- `docs/agent-script-protocol.md` — how changes are delivered
